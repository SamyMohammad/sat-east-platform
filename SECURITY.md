# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub private vulnerability reporting:
the **Security** tab of this repository, then **Report a vulnerability**. Do not open a public
issue or pull request for a security problem.

Include what you found, the steps to reproduce it, and the impact you expect. We aim to
acknowledge a report within a few days.

## Scope

In scope: the web and mobile client in `apps/client/`, the Supabase schema, RLS policies and
RPCs in `supabase/`, the Edge Functions, and the CI workflows.

Out of scope: third-party services (Supabase, Cloudflare, and others) and issues that need a
compromised device or account.

## Rewards

This is a small project and does not run a bug bounty. We will credit reporters who want it.
