# 14 — Glossary

| Term | Meaning |
|------|---------|
| SAT | US college admission test; digital, adaptive; Math section scored 200–800 |
| EST | Egyptian Scholastic Test used for American-Diploma admissions in Egypt; separate course here |
| Bluebook | College Board's official digital testing app; our exam screen simulates its experience |
| Module | One timed half of the SAT Math section (22 questions, 35 min) |
| Adaptive routing | Module 2 difficulty chosen by Module 1 performance |
| MCQ | Multiple-choice question (4 options) |
| SPR / Grid-in | Student-Produced Response — student types a numeric answer |
| Desmos | Graphing calculator embedded in the digital SAT; commercial API needed |
| Topic / Subtopic | Syllabus units: ~40 SAT topics, each split into subtopics (e.g. Linear → Parallel & Perpendicular) |
| Skill | Fine-grained tag (code like `ALG.LIN.SLOPE`) used for analytics |
| Step | One of Video, Notes, Practice, Homework, Quiz inside a topic |
| Pool | Partition of a topic's questions: practice / quiz / mock_reserve |
| Spiral question | Quiz question from an earlier topic to fight forgetting |
| Review set | Targeted practice required after failing a quiz |
| Drill set | Targeted practice generated after a mock |
| Mastery | 0–100 per-skill score (EWMA) |
| Mock form | A frozen, teacher-reviewed mock: M1 + M2E + M2H |
| Mock set | Group of forms; renewal unlocks the next set |
| Access window | Enrollment validity period (test date + grace, min duration) |
| Activation code | One-time code granting enrollment (offline payments) |
| Double-solve | Two independent AI solves; agreement → auto-approve candidate |
| RLS | Postgres Row-Level Security (Supabase) |
| EF | Supabase Edge Function |
| DRM | Encrypted video playback (Widevine/FairPlay) |
| ADR | Architecture Decision Record |
