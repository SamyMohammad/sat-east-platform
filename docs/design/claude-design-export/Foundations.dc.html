Rules for math
Inline math never breaks inside an expression; the line breaks around it.
Block equations scroll horizontally inside their frame when they exceed the column. They never shrink below the text size.
Math follows MediaQuery.textScaler with the body text.
Inside RTL paragraphs, each expression is wrapped in an LTR isolate.
