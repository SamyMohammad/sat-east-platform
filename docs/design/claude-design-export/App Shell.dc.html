Shell rules
Breakpoints≤600 bottom nav · 600–1024 rail · ≥1024 sidebar (NavigationBar / NavigationRail / NavigationDrawer, permanent)
Active destinationprimary.container indicator, radius.sm, filled icon, bold label. Shape and weight change, not only colour.
Focus modeAll navigation removed. Exit only through the close action and a confirmation dialog. Tablet follows the laptop layout with the margin column stacked under the question.
Keyboard (web)Skip link to content; Tab order: navigation → top bar → content. In focus mode: ←/→ previous/next, A–D select, Shift+A–D eliminate, M mark.
