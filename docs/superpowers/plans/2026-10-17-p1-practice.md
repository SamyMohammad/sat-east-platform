# P1 part 4 — Practice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (router dispatches `implementer` per task, reviews each diff). Steps use `- [ ]`.
> On approval this file is copied to `docs/superpowers/plans/2026-10-17-p1-practice.md` and committed (by path) on `feat/P1-practice`.

**Goal:** A student taps an open topic on the course map and practises 10 server-graded questions in `QuestionView` (hint on 1st miss, key + explanation on correct or 2nd miss), with `practice_count` tracking distinct questions.

**Architecture:** Lock rule moves into `private.topic_states` (read by `get_course_map` and the new RPCs). Two security-definer RPCs: `get_practice_questions(p_topic_id)` creates a practice attempt and draws keyless questions; `check_practice_answer(p_attempt_id, p_question_id, p_answer, p_time_ms)` grades, logs tries, replays repeats, reveals on correct / wrong try 2. Client feature `lib/features/practice/` (data → domain → Cubit → screen) replaces the topic stub route.

**Tech stack:** Postgres/plpgsql + pgTAP, Flutter, flutter_bloc, get_it, go_router, supabase_flutter, bloc_test + mocktail.

**Spec:** `docs/superpowers/specs/2026-10-17-p1-practice-design.md` (approved). Tier **L**.

## Context
Part 3 (course map, #29) merged; tapping a topic opens a stub. Part 4 makes practice real and produces the `practice_count` part 5 reads. Students cannot select `questions` / `question_keys` (RLS teacher-only), so all reads go through RPCs.

## Global Constraints
- Errors `raise exception '<code>'` (P0001), docs/07 §9: `not_authenticated`, `invalid_input`, `not_enrolled`, `access_expired`, `topic_locked`, `pool_exhausted`.
- RPCs from `supabase/templates/rpc.sql`: `security definer`, `set search_path = ''`, fully qualified names, `auth.uid()` check first, `revoke … from public, anon; grant execute … to authenticated`. Private helpers revoked from `public, anon, authenticated`.
- No key / explanation / hint / misconceptions in `get_practice_questions`. `check_practice_answer` reveals key + explanation only on a correct try or a wrong try 2; wrong try 1 returns `hint_md` + `misconception_md` only.
- Set size = `private.setting_int('practice_min')` (10). No new settings.
- `practice_count` = distinct practice questions of the topic answered at least once (user decision).
- Client never decides correctness, reveal, lock or counts. No codegen; domain imports no flutter/supabase; cubit depends on repository interface; `isClosed` after awaits; injected `DateTime Function() now` (pattern: `device_gate_screen.dart`).
- Commit by path only (never `git add -A`; `.codex/`, `.impeccable/`, `.vscode/` stay untracked).
- Test names prefixed `PRC-01` / `L-4`; commits `feat(P1)/test(P1)/fix(P1)`.

## Review Focus
1. **Lost reply then retry** of the same answer → replayed, nothing logged, `practice_count` unchanged (Task 2 pgTAP; Task 4 cubit test).
2. **Topic re-locked or enrolment expired mid-set** → `check_practice_answer` raises `topic_locked`/`access_expired`; screen shows the copy, not a crash (Task 2 + Task 5 widget test).
3. **SPR equivalent / malformed input** (`.5` vs `1/2`, `abc`) → graded, never an exception (Task 2).
4. **Pool smaller than 10 / empty** → shorter set with `rep_target` = n / `pool_exhausted` empty state (Task 2 + Task 5).
5. **Cold deep link to a locked topic URL** → "This topic is locked. Pass the previous quiz first." (Task 5 widget test).

### Task 2: Practice RPCs + pgTAP + docs

**Files:** Create `supabase/migrations/20261017100100_prc01_practice.sql`, `supabase/tests/16_practice.test.sql`. **Consumes:** `private.topic_states`, `private.grade_spr(text, jsonb) returns boolean` (raises on malformed answer → catch → false), `private.setting_int('practice_min')`.

**Produces (exact JSON):**
- `get_practice_questions(p_topic_id uuid) → {"attempt_id","rep_target","questions":[{"id","type":"mcq|spr","difficulty":"E|M|H","stem_md","choices":[{"label","body_md"}]}]}`
- `check_practice_answer(p_attempt_id uuid, p_question_id uuid, p_answer text, p_time_ms int) →`
  correct `{"is_correct":true,"try":1|2,"key":K,"explanation_md"}` · wrong try 1 `{"is_correct":false,"try":1,"hint_md","misconception_md"}` · wrong try 2 `{"is_correct":false,"try":2,"key":K,"explanation_md"}`; `K` = `{"choice":"B"}` or `{"text":"<accepted[0]>"}`.

**Algorithm decisions (spec §1.2–1.6):**
- Access helper `private.practice_access(p_uid, p_topic_id) returns uuid /*course_id*/`: topic published else `invalid_input`; enrolment none → `not_enrolled`; status≠active or expired → `access_expired`; `topic_states` status `locked` → `topic_locked`.
- Draw: `pool='practice' and status='published' and topic_id=p_topic_id`, `order by (exposure row is null) desc, random() limit practice_min`; 0 rows → `pool_exhausted`. Insert attempt (`kind 'practice'`, `in_progress`, course_id, topic_id), `attempt_questions` positions 1..n, `question_exposure` on conflict do nothing.
- Check: attempt owned by caller, kind practice, in_progress, contains question, else `invalid_input`; re-run access helper. Normalise answer (MCQ `upper(trim)`, SPR `trim`); empty or > 32 chars → `invalid_input`; `time_ms` clamped `0..3600000`. Stored `answer = {"tries":[...]}`. Equal to last stored try → replay its result (no write). No row → try 1 insert; one wrong try → try 2 update (append, `is_correct`, `time_ms +=`); else `invalid_input`.
- `practice_count`: on try 1 only, `+1` iff no other `attempt_answers` row for this user + question in any practice attempt (upsert `topic_progress`).
