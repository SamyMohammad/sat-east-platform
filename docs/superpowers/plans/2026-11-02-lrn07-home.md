# LRN-07 Student Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo, tasks are delegated to Codex via `codex-delegate`; Claude reviews and commits.

**Goal:** Replace the Home placeholder with a "Continue where you left off" screen and hide the disabled notifications bell.

**Architecture:** New feature `lib/features/home/` (data/domain/presentation). A `GetHomeSummary` use case composes existing repositories (`CourseMapRepository`, `TopicRepository`, `AuthRepository`) plus one new settings read; a pure `currentStepOf(TopicDetail)` picks the next step. `HomeCubit` → `HomeScreen`. One SQL migration adds a setting row.

**Tech Stack:** Flutter, flutter_bloc (Cubit), get_it, go_router, supabase_flutter, mocktail, bloc_test; Supabase Postgres + pgTAP.

**Spec:** `docs/superpowers/specs/2026-11-02-lrn07-home-design.md`

## Global Constraints
- English-only UI copy, LTR (CLAUDE.md rule 8). All copy lives in `home_copy.dart`.
- No magic numbers: warn threshold comes from setting `access_expiry_warn_days` (default 14).
- Layers: presentation has no logic; `domain/` imports neither `package:flutter` nor `package:supabase_flutter`.
- Repositories return `Result<T>` (`lib/core/errors/result.dart`); errors carry `ErrorCodes` (`lib/core/errors/error_codes.dart`).
- No codegen; sealed classes + exhaustive `switch`; Equatable entities like the existing ones.
- Inject a clock (`DateTime Function() now`) — no real `DateTime.now()` in domain/cubit.
- Cubit: check `isClosed` after every `await`. DI only in `lib/core/di/injection.dart` (factory for cubit, lazy singleton for repo/data source).
- Test names carry `LRN-07:`. Deterministic tests only.
- Do not touch `.codex/`, `.impeccable/`, `.vscode/`, `.wrangler/`, `content/`. Do not commit.

## Review Focus
1. Topic with **no videos** or **no notes** — that step counts as done; Home must not point at a video/notes route with no asset. (Task 2 test.)
2. `get_course_map` **preview access** (`CourseAccess.preview`, CRS-06) or `not_enrolled` — Home must show the not-enrolled state, not a continue card into a preview topic. (Task 2 test.)
3. **Several enrolments** — pick the one whose `courseId` equals the map's course id; if none matches, no banner. (Task 2 test.)
4. **Expiry exactly at threshold** / already past — banner only when `0 < daysLeft < warnDays`; `daysLeft` counted in whole days from injected `now`. (Task 2 test.)
5. `get_topic` **fails** after the map loads — whole summary is a `Failure` (retryable), never a half-empty card. (Task 2 test.)

**Interfaces:**
- Consumes: `CourseMapRepository.getCourseMap({String? slug})`, `TopicRepository.getTopic(String)`, `AuthRepository.getMyProfile()`, `AuthRepository.listMyEnrollments()`, `MyEnrollment.courseId` (Task 1), entities `CourseMap`, `ContinueTopic`, `MapTopic`, `TopicStatus`, `CourseAccess`, `TopicDetail`, `QuizStatus`, `TopicHomework`, `HomeworkState`.
- Produces:
  ```dart
  sealed class CurrentStep { int get index; }            // 1..5
  final class VideoStep(TopicVideo video)                // index 1, first video with pct < 80 … else first
  final class NotesStep(TopicNote note)                  // 2
  final class PracticeStep(int count, int min)           // 3
  final class HomeworkStep(TopicHomework homework)       // 4
  final class QuizStep(QuizStatus quiz)                  // 5
  CurrentStep currentStepOf(TopicDetail t);

  abstract interface class HomeSettingsRepository { Future<Result<int>> expiryWarnDays(); }

  sealed class HomeSummary;
  final class HomeReady(String firstName, String courseTitle, String unitTitle,
      ContinueTopic topic, String topicSortLabel, CurrentStep step, bool firstRun,
      int passed, int total, ExpiryWarning? expiry)
  final class HomeFinished(String firstName, String courseTitle, int total)
  final class HomeExpired(String firstName)
  final class HomeNotEnrolled(String firstName)
  final class ExpiryWarning(int daysLeft, DateTime expiresAt)

  class GetHomeSummary {
    GetHomeSummary(CourseMapRepository, TopicRepository, AuthRepository,
        HomeSettingsRepository, DateTime Function() now);
    Future<Result<HomeSummary>> call();
  }
  ```
  `currentStepOf` rule (spec table): first not done of video (`videoDone || videos.isEmpty`), notes (`notesDone || notes.isEmpty`), practice (`practiceCount >= practiceMin`), homework (`state` in `submitted`/`skipped`), else quiz. `VideoStep.video` = first video with `pct < 80`, else first.
  `firstName` = first whitespace-separated word of `fullName` (trimmed; empty name → `''`).
  `firstRun` = `passed == 0 && step is VideoStep && every video pct == 0`.
  `topicSortLabel` = `MapTopic.sortLabel` of the continue topic found in `units`.
  Error mapping: map `Failure` code `notEnrolled` → `Success(HomeNotEnrolled)`, `accessExpired` → `Success(HomeExpired)`; `access == preview` → `HomeNotEnrolled`; `continue == null` → `HomeFinished`; any other failure (map, topic, profile) → `Failure` unchanged. Settings/enrollment failure → `expiry = null` (banner is optional, not fatal). `daysLeft = expiresAt.difference(now()).inDays`; warning when `0 < daysLeft < warnDays`.
