# F-4 Design Gallery Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development. The `test-writer` agent writes every `*_test.dart` (a project hook enforces this). An `implementer` agent writes production code. Each task is reviewed before the next. Steps use checkbox syntax.

**Goal:** Add a `/gallery` route, hidden in prod, that shows all 17 `QuestionView` mode/state entries from static sample data. It is reviewed on staging at 360 and 1280, and it closes the UI part of Phase 0.

**Architecture:**
- The code is presentation only, in `apps/client/lib/features/design_gallery/presentation/`.
- An ordered `galleryEntries` list holds frozen `QuestionView` builders, with no-op callbacks.
- `GalleryScreen` shows one entry, picked by the `?entry=` query parameter. The URL is the only state, so there is no Cubit.
- One small `StatefulWidget` opens an entry's overlay after the first frame. That is local UI state, which B.1 allows.
- The route sits outside the shell and is registered only when `includeGallery` is true (default `Env.flavor != Flavor.prod`).

**Tech Stack:** Flutter 3.44.1, go_router, flutter_test. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-15-f4-gallery-design.md` (committed on `feat/F-4-gallery`, 0135f3e).

## Global Constraints

- Presentation only. No `data/` / `domain/` folders, no Cubit, no `get_it` registration (spec §1).
- English UI copy. Content samples go through `QuestionView` / `MathText`, and one explanation includes an Arabic paragraph (rule 8).
- Use only the public QuestionView APIs:
  - `QuestionView`, `QuestionData`, `AnswerState`;
  - the `PracticeMode` / `HomeworkMode` / `QuizMode` feedback types;
  - `showHomeworkNavigatorSheet`, `showNavigatorSheet`, `showNavigatorPopover`, `showSubmitConfirmDialog`, `showQuizTimeUpDialog`.

  Do not change anything under `lib/shared/widgets/question_view/`.
- Sizes come from Booklet tokens, and the breakpoint from `BookletLayout.forWidth`. No magic numbers.
- Navigation uses `context.go` only, never `Navigator.push`.
- Test names start with `F-4:`. No new goldens.
- Never commit `.codex/` or `.impeccable/` (they are staged and unrelated).

## Review Focus

## Public interfaces

```dart
// lib/features/design_gallery/presentation/gallery_entries.dart
@immutable
final class GalleryEntry {
  const GalleryEntry({required this.id, required this.label, required this.builder, this.openOverlay});
  final String id;                          // e.g. 'quiz-warning'
  final String label;                       // e.g. 'Quiz · 5-min warning'
  final WidgetBuilder builder;              // returns the QuestionView (no Scaffold)
  final void Function(BuildContext context)? openOverlay;
}
final List<GalleryEntry> galleryEntries;    // 17, order below
GalleryEntry galleryEntryById(String? id);  // unknown/null → galleryEntries.first

// lib/features/design_gallery/presentation/gallery_screen.dart
// StatefulWidget only to hold a GlobalKey; never calls setState
class GalleryScreen extends StatefulWidget { const GalleryScreen({required this.entryId, super.key}); final String? entryId; }

// lib/core/router/app_router.dart
abstract final class AppRoutes { ... static const gallery = '/gallery'; }
GoRouter createRouter({String? initialLocation, bool? includeGallery}); // null → Env.flavor != Flavor.prod
String galleryLocation(String id) => Uri(path: AppRoutes.gallery, queryParameters: {'entry': id}).toString();
```

## Task 2 — Gallery screen and route

**Consumes:** Task 1.

**Produces:** `GalleryScreen`, `AppRoutes.gallery`, `galleryLocation`, `createRouter(includeGallery:)`.

`GalleryScreen` layout:
- `Scaffold(appBar: AppBar(title: Text('Design gallery'), actions: [...]), body: _EntryHost(entry: entry))`, where `entry = galleryEntryById(entryId)` and `index = galleryEntries.indexOf(entry)`.
- **Actions:**
  - a `DropdownButton<String>` with value `entry.id`, items of entry labels, and `onChanged: (id) => context.go(galleryLocation(id!))`;
  - an `IconButton(Icons.chevron_left)` with tooltip "Previous entry", null at index 0;
  - an `IconButton(Icons.chevron_right)` with tooltip "Next entry", null at the last index;
  - a `TextButton('Reopen')`, only when `entry.openOverlay != null`, which calls `_hostKey.currentState?.reopen()`.

  `GalleryScreen` is a `StatefulWidget` only to hold `final _hostKey = GlobalKey<_EntryHostState>()`. It never calls `setState`.
- **`_EntryHost` (StatefulWidget):**
  - `initState`, and `didUpdateWidget` when `oldWidget.entry.id != widget.entry.id`, call `_scheduleOverlay()`.
  - `_scheduleOverlay()` runs `WidgetsBinding.instance.addPostFrameCallback((_) { if (!mounted) return; _closeOverlays(); widget.entry.openOverlay?.call(context); })`.
  - `_closeOverlays()` pops `PopupRoute`s on `Navigator.of(context, rootNavigator: true)` and on `Navigator.of(context)`, using `popUntil((r) => r is! PopupRoute)`.
  - `build` returns `widget.entry.builder(context)`.
  - The `Reopen` path is `_closeOverlays()` followed by `openOverlay`.
- **Narrow AppBar:** at 360 px the dropdown must not overflow. Wrap it in `Flexible` with `isExpanded: true`, and use ellipsized item text.

Router:
- Add `AppRoutes.gallery = '/gallery'` and `galleryLocation`.
- `createRouter({String? initialLocation, bool? includeGallery})` adds a top-level `GoRoute(path: AppRoutes.gallery, builder: (context, state) => GalleryScreen(entryId: state.uri.queryParameters['entry']))` after the `StatefulShellRoute`, when `includeGallery ?? Env.flavor != Flavor.prod`.
